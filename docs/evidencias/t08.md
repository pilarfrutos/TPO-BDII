# T08 · Consultas de catálogo, ventas y stock

Las cuatro consultas usan agregaciones de MongoDB. Para reproducir los
resultados de esta página desde la raíz del proyecto, con `.env` y las
dependencias ya preparados según el [README](../../README.md):

```sh
docker compose up -d --wait mongo mongo-init
python3.12 tests/queries/verify.py --evidencia
```

La prueba carga los CSV originales en una base temporal, prepara los casos
indicados abajo, comprueba los resultados y elimina la base al terminar.

## q01 · Productos activos y sus proveedores

`q01(db)` recibe la base de MongoDB. Devuelve una lista de productos activos
ordenados por `id_producto`, cada uno con el documento completo del proveedor.
La agregación filtra `productos.activo` y une `productos` con `proveedores`
por `id_proveedor`. El filtro de actividad se aplica al producto.

La prueba marcó `PRV001` como inactivo y q01 devolvió **11 productos**, entre
ellos `PRD001` (Paracetamol 500mg x30), con este documento en `proveedor`:

```json
{
  "id_proveedor": "PRV001",
  "razon_social": "Laboratorios Andinos S.A.",
  "cuit": "30-71234567-1",
  "tipo": "Laboratorio",
  "ciudad": "Buenos Aires",
  "provincia": "Buenos Aires",
  "telefono": "1143001100",
  "activo": false
}
```

## q07 · Cinco productos más vendidos

`q07(db)` recibe la base de MongoDB. Devuelve hasta cinco registros con
`id_producto`, `producto` y `unidades`. Une las ventas completadas con sus
detalles por `id_venta`, suma las cantidades por `id_producto` y busca el
nombre del producto. Ordena por unidades descendentes y, ante un empate, por
ID ascendente.

## q08 · Lotes con menos de 50 unidades

`q08(db)` recibe la base de MongoDB. Devuelve una lista de lotes con ID,
número de lote, unidades, vencimiento y datos de producto, sucursal y
proveedor. Une los lotes con productos y sucursales por sus IDs y obtiene el
proveedor por `producto.id_proveedor`.

| Lote | Unidades | Vencimiento | Producto | Sucursal | Proveedor |
| --- | ---: | --- | --- | --- | --- |
| L018 | 15 | 2026-09-30 | Alcohol en gel 250ml | Farmacia Belgrano | DroguMed S.R.L. |
| TEST-49 | 49 | 2027-08-31 | Paracetamol 500mg x30 | Farmacia Palermo | Laboratorios Andinos S.A. |

El lote original `L018` aparece aunque esté vencido. De los dos lotes que
agrega la prueba, aparece `TEST-49` y queda afuera `TEST-50`.

## q11 · Ingresos por farmacéutico en el mes actual

`q11(db)` recibe la base de MongoDB y toma el mes de la fecha actual en Buenos
Aires. Devuelve una lista con ID, nombre, apellido, matrícula e ingresos en
pesos por farmacéutico con ventas completadas en el período. Filtra desde el
primer día del mes hasta el primer día del mes siguiente, excluido. Suma
`ventas.total` por `id_farmaceutico` y usa ese ID para obtener los datos del
profesional.

La prueba llama a `q11(db, hoy=date(2026, 10, 20))` para reproducir octubre de
2026. Agrega una venta completada de $9.800 el 1 de octubre y otra el 1 de
noviembre. Solo la de octubre suma a los ingresos de F001 en este resultado.

| ID | Farmacéutico | Matrícula | Ingresos (ARS) |

| F001 | Mariana Quiroga | MN-18041 | 14.200 |
| F002 | Sebastián Ledesma | MN-18078 | 7.800 |
| F003 | Carolina Benítez | MN-18112 | 7.100 |
| F005 | Natalia Giménez | MN-18189 | 4.600 |
